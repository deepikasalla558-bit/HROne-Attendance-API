# Employee Attendance and Analytics API

## Project Overview
This project is an Employee Attendance and Analytics API built using Python, FastAPI, and MongoDB.

## Features
- Employee management
- Attendance punch-in and punch-out
- Attendance correction
- Attendance history and audit logs
- Daily attendance analytics and employee working hours

## Technologies Used
- Python
- FastAPI
- MongoDB
- PyMongo

## Setup
Install the dependencies using:

pip install -r requirements.txt

Configure MongoDB before running the application.

## Project Status
Implementation and testing are in progress. Some requirements may not be fully implemented or tested yet.
